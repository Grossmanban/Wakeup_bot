# Роли и разрешения

Роль определяет **область видимости**, разрешения — **допустимые действия**. Все проверки
выполняются на сервере (`backend/app/services/access.py`) на каждом запросе.

## Роли

| Роль | Область видимости | Права по умолчанию |
|---|---|---|
| Владелец | Вся система | Все действия |
| Администратор | Люди из сетей, указанных в разрешении, или все — если разрешение выдано на «все сети» | Нет |
| Тренер | Своя команда: инструкторы и их сотрудники, а также закреплённые напрямую | Просмотр своей команды |
| Инструктор | Свои сотрудники | Просмотр своих сотрудников |
| Сотрудник | Только свои данные | Нет |

Тренеру и инструктору тоже можно выдать разрешения, но действуют они только внутри их команды.
Чужие объекты возвращают «не найдено» (404), чтобы нельзя было перебором узнать ID.

## Разрешения

Выдаёт только владелец в карточке сотрудника; каждое — на «все сети» или на конкретные сети.

| Код | Действие | Раздел |
|---|---|---|
| `users.view` | Просмотр сотрудников и их показателей | Сотрудники |
| `registrations.review` | Рассмотрение заявок на регистрацию (новые заявители ещё не в сетях — ограничение по сети не действует) | Заявки |
| `name_changes.review` | Подтверждение смены ФИО | Заявки |
| `users.status` | Включение, отключение, блокировка (кроме владельца, администраторов и себя) | Карточка сотрудника |
| `org.manage` | Сети и команды; создавать сети — только с правом на «все сети» | Сети, карточка |
| `audit.view` | Журнал аудита и история сотрудника | Журнал аудита |
| `schedule.view` | Сводка по дням и «Распред» | График |
| `schedule.manage` | Подтверждение и правка смен сотрудников | График |
| `tasks.import` | Импорт заданий из Excel | Импорт |
| `tasks.manage` | Пул и задания: просмотр, возврат в пул, отмена | Задания |
| `moderation.review` | Модерация (кроме своих заданий) | Модерация |
| `ocr.manual_review` | Ручная проверка фото и сообщения об ошибках | Ручная проверка |
| `finance.view` | Просмотр финансов сотрудников | Карточка |
| `finance.manage` | Штрафы, бонусы, корректировки, правила бонусов и «налога на лень» | Финансы |
| `payouts.manage` | Расчёт и подтверждение выплат | Выплаты |
| `goals.manage` | Цели и соревнования | Цели |
| `candidates.review` | Анкеты кандидатов, ответственный, сообщение по шаблону | Кандидаты |
| `referrals.use` | Персональная реферальная ссылка и QR-код | Профиль |
| `training.manage` | Обучение: назначение, отмена, «Начать обучение», подтверждение учебных единиц | Кандидаты, Стажёры |
| `broadcasts.send` | Рассылки в пределах своей области | Рассылки |
| `groups.view` | Членство в группах, проверка, прогресс новичков | Членство |
| `groups.invite` | Приглашения в группы | Членство, карточка |
| `stats.view` | Статистика по сотрудникам | Статистика |
| `export` | Выгрузка XLSX/CSV | Статистика |

## Только владелец

Не выдаются никому: назначение ролей, выдача разрешений, доступ к Mini App, продукты и
продуктовые доступы, ставки, пол сотрудника, рабочие точки, Telegram-группы, маршруты
фотоотчётов, архив аудита, системные настройки, повтор отправки фотоотчётов.

Роль владельца — только через `OWNER_TELEGRAM_IDS`.

## Состояние аккаунта

Отключённый, заблокированный или без доступа к Mini App аккаунт получает 403 на всех рабочих
разделах; в боте ему недоступны «Я ознакомился» и ответы на рассылки.
