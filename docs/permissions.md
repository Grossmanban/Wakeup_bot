# Роли и разрешения

Роль определяет **область видимости**, разрешения — **допустимые действия**. Все проверки
выполняются на сервере (`backend/app/services/access.py`).

## Роли

| Роль | Область видимости | Права по умолчанию |
|---|---|---|
| Владелец | Вся система | Все действия |
| Администратор | Люди из сетей, указанных в разрешении, или все, если разрешение выдано на «все сети» | Нет |
| Тренер | Своя команда: инструкторы и их сотрудники, а также сотрудники, закреплённые напрямую | Просмотр своей команды |
| Инструктор | Свои сотрудники | Просмотр своих сотрудников |
| Сотрудник | Только свои данные | Нет |

Тренеру и инструктору тоже можно выдать разрешения, но действуют они только внутри их команды.

## Разрешения

Выдаёт только владелец, в карточке сотрудника. Каждое разрешение выдаётся на «все сети»
или на конкретные сети.

| Код | Действие |
|---|---|
| `users.view` | Просмотр сотрудников |
| `registrations.review` | Рассмотрение заявок на регистрацию (новые заявители ещё не в сетях, поэтому ограничение по сети здесь не действует) |
| `name_changes.review` | Подтверждение смены ФИО |
| `users.status` | Включение, отключение и блокировка (кроме владельца, администраторов и себя) |
| `org.manage` | Сети и команды. Создавать и переименовывать сети можно только с разрешением на «все сети» |
| `audit.view` | История изменений сотрудника |

Эти разрешения заведены заранее для следующих этапов, эндпоинтов под ними пока нет:
`schedule.view`, `schedule.manage`, `tasks.import`, `tasks.manage`, `moderation.review`,
`ocr.manual_review`, `finance.view`, `finance.manage`, `payouts.manage`, `goals.manage`,
`candidates.review`, `training.manage`, `broadcasts.send`, `groups.view`, `groups.invite`,
`stats.view`, `export`.

## Только владелец

Эти действия не выдаются никому: назначение ролей, выдача разрешений, доступ к Mini App,
продукты и продуктовые доступы, ставки, настройки групп и фотоотчётов, системные настройки.
