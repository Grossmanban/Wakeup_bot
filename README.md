# Wakeup

Telegram-бот и Mini App для управления сотрудниками, заданиями, графиком, финансами,
аналитикой и фотоотчётами.

## Возможности

- **Скрытый режим:** посторонним бот не отвечает; новые люди — по реферальной ссылке с анкетой,
  действующие сотрудники — по персональному приглашению владельца; журнал попыток доступа.
- **Регистрация и доступ:** смена ФИО, роли (владелец, администратор,
  тренер, инструктор, сотрудник), разрешения по сетям, команды, отключение и блокировка.
- **Продукты и задания:** настраиваемые этапы с чек-листами и минимальным временем, фото с
  камеры, OCR текста на фото, импорт из Excel с предпросмотром, пул заданий без двойной выдачи.
- **Модерация и ручная проверка** фото, история решений, качество.
- **График:** смены на рабочих точках с вместимостью, планы по продуктам, выходные,
  подтверждение, сроки правки, «Распред».
- **Финансы:** ставки по ролям и людям, журнал начислений, штрафы, бонусы и автоматические
  правила, «налог на лень», расчёт и подтверждение выплат с удержанием долгов.
- **Люди:** цели и соревнования, анкеты кандидатов, обучение, реферальные ссылки и QR.
- **Статистика:** качество, производительность, заработок, почасовое распределение, выгрузка
  XLSX/CSV.
- **Telegram-группы:** членство, приглашения, прогресс новичков, фотоотчёты по продуктам с
  ежедневным заголовком и сводкой, рассылки с «Я ознакомился», архив журнала аудита по темам.

## Состав

## Запуск на сервере

Нужен сервер с Ubuntu/Debian и домен, A-запись которого указывает на сервер (Telegram
открывает Mini App только по HTTPS).

### Быстрая установка (рекомендуется)

По SSH на сервере:

```sh
git clone https://github.com/Grossmanban/Wakeup_bot.git /opt/wakeup
sudo bash /opt/wakeup/deploy/install.sh
```

Скрипт сам поставит Docker, спросит токен бота (и проверит его в Telegram), ваш Telegram ID,
домен (проверит, что он указывает на сервер), режим OCR, сгенерирует пароль БД, запишет `.env`,
включит ежедневные резервные копии, соберёт и запустит сервисы, настроит кнопку меню бота.
Для домена DuckDNS можно указать токен — IP будет обновляться автоматически.

Обновление и смена настроек — та же команда: Enter оставляет прежние значения.

### Владельцы и диагностика

```sh
sudo bash deploy/owners.sh                   # кто владелец сейчас
sudo bash deploy/owners.sh people            # последние, кто открывал бота: имя, @username, ID
sudo bash deploy/owners.sh add @username     # добавить владельца по username…
sudo bash deploy/owners.sh add 123456789     # …или по Telegram ID
sudo bash deploy/owners.sh remove 123456789  # убрать (станет администратором без разрешений)
sudo bash deploy/doctor.sh                   # почему не открывается Mini App
```

Роль выдаётся сразу (человеку достаточно закрыть и снова открыть приложение). Если человек
ещё не открывал бота, роль появится при первом входе. Скрипт показывает, чей это ID.

### Рядом с другим приложением

Скрипт не мешает другим приложениям на сервере (например, другому боту в `/opt/bot_sanya`):

- у Wakeup свой проект Docker `wakeup` — свои контейнеры и тома; Docker не переустанавливается
  и не перезапускается, чужие контейнеры не затрагиваются;
- если токен бота или домен уже указаны в `.env` другого приложения в `/opt`, скрипт попросит
  другой: два процесса не могут получать обновления одного бота;
- если порты 80/443 заняты Caddy соседа (как у `bot_sanya`), скрипт предлагает **подключить
  Wakeup к этому Caddy** (рекомендуется): адрес без порта `https://<домен>/`, сертификат
  выпускает Caddy соседа. В папке соседа появляются два файла вне git —
  `docker-compose.override.yml` и `Caddyfile.wakeup`; его собственный Caddyfile подключается
  через `import` без изменений, а обновления соседа (`git reset --hard`) эти файлы не трогают.
  Перед применением конфигурация проверяется (`caddy validate`), при ошибке всё возвращается
  как было. Связь — общая Docker-сеть `wakeup_edge`, Wakeup в ней называется `wakeup-web`.
  Отключить: удалить эти два файла и выполнить `docker compose up -d caddy` в папке соседа;
- если подключиться нельзя или вы отказались, Wakeup открывается на отдельном порту — по
  умолчанию `https://<домен>:8443/`, сертификат через DNS-проверку DuckDNS (нужен домен
  `*.duckdns.org` и токен DuckDNS). Некоторые мобильные операторы закрывают нестандартные порты.

Кнопка «Открыть» в списке чатов — главное мини-приложение из @BotFather (Bot Settings →
Configure Mini App): там должен быть ровно тот адрес, который скрипт вывел в конце.

### Требования к серверу

| | Без OCR (`none`) | С OCR (`onnx`) |
|---|---|---|
| Процессор | 1 vCPU | 1–2 vCPU |
| Память | 1 ГБ | 1,5–2 ГБ |
| Диск под систему и образы | 10 ГБ | 10 ГБ |

Фото — около 0,5 МБ каждое и хранятся бессрочно: 100 фото в день ≈ 1,5 ГБ в месяц,
1000 фото в день ≈ 15 ГБ в месяц. Резервная копия фото — зеркало (ещё столько же места), плюс
дампы БД за 14 дней. Копии на том же диске не спасут от поломки сервера — периодически
скачивайте папку `backups` к себе или на другой сервер.

### Вручную

1. Создайте бота у @BotFather и получите токен.
2. Скопируйте `.env.example` в `.env` и заполните: `BOT_TOKEN`, `BOT_USERNAME`, `DOMAIN`,
   `MINIAPP_URL`, `POSTGRES_PASSWORD`, `OWNER_TELEGRAM_IDS`.
3. `docker compose up -d --build`
4. В @BotFather (Bot Settings → Configure Mini App) укажите адрес `https://<DOMAIN>/`.
5. Откройте бота, нажмите /start → «Открыть приложение». Владелец входит без заявки и
   один раз указывает ФИО.

Миграции применяются автоматически при старте контейнера `api`. HTTPS-сертификат Caddy
получает сам.

### Настройка Telegram

1. Добавьте бота в каждую рабочую группу и сделайте **администратором** с правами
   «Пригласительные ссылки» (для приглашений) и «Управление темами» (для архива аудита).
   Только администратор получает от Telegram события о вступлении и выходе участников.
2. Группа появится в «Управление → Группы». Там владелец указывает её назначение: обучение,
   основная, фотоотчёты, сводка, архив аудита или другое.
3. В «Фотоотчёты» назначьте группы продуктам, общую группу и группу сводки.
4. Для архива аудита включите в группе темы (форум) и нажмите «Создать темы архива» в карточке группы.

### Фоновые задачи

Выполняются процессом `bot` раз в минуту; каждая задача отмечается в `job_runs`, поэтому
перезапуск не создаёт дублей.

| Время (МСК) | Задача |
|---|---|
| каждую минуту | отправка очереди сообщений с повторами, выгрузка журнала аудита в архив |
| каждый час | исправления сводок фотоотчётов, если решения модерации изменились |
| 00:05 (`daily_summary_time`) | сводка фотоотчётов за прошедший день, затем заголовок нового дня |
| 00:10 | закрытие дня по «налогу на лень» |
| 00:20 | пересчёт прогресса новичков |

### OCR

Модели PP-OCRv5 (поиск текста + славянская модель распознавания) работают через ONNX Runtime:
бесплатно, на своём сервере, без внешних сервисов. Около 0,5 ГБ памяти в пике и ~1 с на фото.
Модели (~13 МБ) скачиваются при сборке образа и проверяются по SHA-256. Если памяти совсем
мало, задайте `OCR_ENGINE=none` — фото с проверкой текста пойдут на ручную проверку.

## Разработка

Backend (нужен PostgreSQL и [uv](https://docs.astral.sh/uv/)):

```sh
cd backend
uv sync
export BOT_TOKEN=... DATABASE_URL=postgresql+asyncpg://wakeup:wakeup@localhost:5432/wakeup OWNER_TELEGRAM_IDS=...
uv run alembic upgrade head
uv run uvicorn app.main:app --reload     # API на :8000
uv run python -m bot.main                # бот и очередь сообщений
```

Тесты используют отдельную БД `wakeup_test` (или `TEST_DATABASE_URL`) и пересоздают схему
миграциями:

```sh
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

Mini App:

```sh
cd webapp
npm install
npm run dev      # :5173, /api проксируется на :8000
npm run build
```

Вне Telegram Mini App показывает «Откройте приложение из Telegram»: вход возможен только
с подписанными initData.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен бота. Не пишется в логи |
| `DATABASE_URL` | Подключение к PostgreSQL (в Compose задаётся автоматически) |
| `POSTGRES_PASSWORD` | Пароль БД для Compose |
| `DOMAIN` | Домен для HTTPS |
| `MINIAPP_URL` | Адрес Mini App для кнопок бота |
| `OWNER_TELEGRAM_IDS` | Telegram ID владельцев через запятую |
| `INIT_DATA_MAX_AGE` | Срок действия подписи входа, секунд (по умолчанию 86400) |
| `CORS_ORIGINS` | Только при раздельных доменах Mini App и API |
| `MEDIA_DIR` | Каталог фотографий (в Compose — том `media`) |
| `BOT_USERNAME` | Имя бота без @ для реферальных ссылок |
| `OCR_ENGINE` | `onnx` (по умолчанию) или `none` |
| `WITH_OCR` | `0` — собрать образ без OCR (для `OCR_ENGINE=none`, меньше на ~300 МБ) |
